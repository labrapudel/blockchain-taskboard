# Итоговый проект — персональный TODO-лист на блокчейне


Проект основан на открытом Scaffold-ETH-2 (https://github.com/scaffold-eth/scaffold-eth-2).
Исходная ревизия шаблона: ed8e5bd18824f98d913372db349ca8bd55283ead. Код проекта находится в TaskBoard.sol и routes /tasks и /tasks/manage.

## Запуск

Требуется Node.js 22.13 или новее и Yarn через Corepack.

1. Распаковать архив и открыть папку taskboard.
2. Выполнить corepack yarn install --immutable.
3. В первом терминале запустить corepack yarn chain.
4. Во втором терминале выполнить corepack yarn deploy.
5. В третьем терминале выполнить corepack yarn start.
6. Открыть http://localhost:3000/tasks или http://localhost:3000/tasks/manage.

Hardhat работает на http://127.0.0.1:8545 с Chain ID 31337. В MetaMask выбрать эту локальную сеть и подключиться через меню кошелька в шапке. Для локальной проверки доступен встроенный Burner Wallet и локальный Faucet. Использовать только тестовые аккаунты.

## Проверка

corepack yarn test запускает тесты TaskBoard и пример теста Scaffold-ETH-2. Тесты TaskBoard проверяют запись и чтение, событие TaskChanged, отклонение некорректных действий и изоляцию записей разных адресов.

## Данные и права

На страницах отображается список подключённого адреса. Контракт позволяет прочитать записи любого адреса. Изменять можно только собственные записи. Названия задач хранятся в блокчейне, поэтому личные данные вводить не следует.
